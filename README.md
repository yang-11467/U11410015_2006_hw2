# 畫世界的板塊交界帶
系級：地生二 學號：U11410015 姓名：林柏揚
地點選擇：東非大裂谷 AB剖面座標：(28, -3), (38, -3)
製圖方法：我擷取老師在03中繪製的日本地區地形範例，並從Google map中找尋東非大裂谷的經緯度，透過改變參數的方式將位在地球上方的虛擬「鏡頭」從日本轉向東非。
<img width="779" height="1342" alt="region_map" src="https://github.com/user-attachments/assets/67622c27-a13c-4caf-bcc3-36bf9a5748f2" />

接下來，我將東非大裂谷的座標以及我所設定的AB剖面座標輸入到剖面圖與地震資料的程式中，其中我在AB剖面中「走廊半寬」的參數部分碰壁了很多次，由於我較不熟悉東非大裂谷的斷層面，「也許」是因為東非大裂谷的斷層面並非平整筆直，所以當我擷取不同的走廊寬度資料時，結果會相差很多。最後我決定使用150m走廊半寬，因為我在觀察不同走廊半寬的地震資料過後，我發現東非大裂谷的地層活動極少且淺，故在圖中較無法觀察出明顯的地層剖面。
雖然無法觀察出地層剖面，但我們可以發現在裂谷正中間的大平坦低谷中的地震數量幾乎沒有資料，少部分的地震資料都集中在裂谷兩側的峰，可以了解到然有可能在活動的地區並非裂谷正中央，而是裂谷的兩側。
<img width="911" height="674" alt="region_section" src="https://github.com/user-attachments/assets/4daac2f3-7a4c-44b0-9517-2df53814eed1" />

接著我將數據貼入速度剖面的程式中，可以從圖中直接觀察到偏藍色的板塊與紅色的地函明顯分開，且藍色的板塊水平於地面，在途中左側與右側有明顯向上，可以連結上一張圖了解到：東非大裂谷底下的板塊在裂谷左右側峰處仍然有所活動，而裂谷正中央的谷底則為筆直的水平板塊，並沒有在活動。

心得與感想：
這次作業對我來說是一個全新的嘗試與挑戰。過去我並不熟悉GitHub和Google Colab這兩個工具，剛開始在進行環境操作和程式碼編輯時花了蠻多時間摸索，幸好有Ai的輔助，讓我能快速掌握這些工具的使用方式與流程。

在實際製圖的過程中，最有成就感也最挫折的部分主要在於調整參數。原本以為只要將東非大裂谷的經緯度與剖面座標輸入即可，但在設定「走廊半寬」時卻卡關許久。透過反覆嘗試不同的走廊寬度並觀察地震資料，我才體會到現實世界中的斷層面並不像課本理論那樣平直，參數的些微差異都會大幅影響資料呈現的結果。

雖然最終產出的地震資料顯示該區域的活動極少且淺，無法繪製出非常顯著的地層剖面，但將地震資料與速度剖面相互對照後，能親自驗證並推論出「裂谷中央相對穩定、活動多集中於兩側山峰」的現象，依然讓我獲益良多。這次的經驗不僅讓我學會了跨區域的地形與地質資料處理，也讓我深刻體會到科學繪圖中「根據資料細節不斷調整並找出合理解釋」的探索樂趣。
